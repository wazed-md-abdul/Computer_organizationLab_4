P4 [Normal]: In this lab, you will explain how a single-cycle CPU carries out an instruction. Predict the values on its active paths, identify the controls that route those values, and distinguish a signal being ready from a register or memory word being updated. Use the Lecture 4 load–add–store example as your reference throughout.
P5 [Heading 2]: Learning outcomes
P6 [Normal]: 1. Trace add, lw, sw and beq through the lecture datapath.
P7 [Normal]: 2. Explain selection controls, write enables and updates at the rising clock edge.
P8 [Normal]: 3. Use internal observations to identify the first incorrect effect of a control fault.
P9 [Normal]: 4. Calculate a fixed clock period from dependent paths and evaluate an optimization.

--- TABLE 1 ---
R0: Item | Convention used in this lab
R1: State and access | 32-bit integer registers; x0 always zero; separate instruction and data memories; aligned 4-byte word accesses.
R2: Timing | Combinational reads; enabled register and memory writes commit at the ending rising edge. Every supported instruction uses one fixed cycle.
R3: ALU input | ALUSrc=0 selects the second register value; ALUSrc=1 selects the signed immediate. The main ALU adds.
R4: Write back | WBsel=0 selects the ALU result; WBsel=1 selects the memory result. RegWrite enables the destination update.
R5: Store and branch | MemWrite enables a store. A dedicated comparator produces Eq; a separate adder computes PC+immediate. PCSel=Branch AND Eq.
R6: Address units | PC and memory addresses count bytes. The decoded branch immediate is already a signed byte offset; do not shift it again.
